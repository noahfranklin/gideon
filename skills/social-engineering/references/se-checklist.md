# Authorized Social-Engineering Checklist

## Authorization & ethics
- [ ] Executive sponsor written authorization
- [ ] Scope: groups, channels, pretext limits
- [ ] No real password storage; no lasting harm; sensitive-lure limits
- [ ] PII minimization + retention/deletion plan
- [ ] Legal/HR review + participant debrief plan

## Design
- [ ] Objective = measurement, not punishment
- [ ] Pretext within sensitivity limits
- [ ] Landing page training-oriented; credential events logged, not stored
- [ ] Group segmentation for metrics

## Execution
- [ ] Sponsor/SOC coordination
- [ ] Simulation identifier embedded
- [ ] Easy "report phishing" path

## Metrics & remediation
- [ ] Aggregate rates (delivered/opened/clicked/submitted/reported/time-to-report)
- [ ] Training tied to results; re-test
- [ ] Technical controls recommended (MFA, DMARC, link/attachment protection)
